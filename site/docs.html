DOCUMENTATION

安装之后，先给一个真实问题。

运行需要能读取 Agent Skill 的宿主。辅助脚本需要 Python 3.10+；没有强制 MCP、API 密钥或付费依赖。

安装与核验调用输入工具与权限无脚本示例完整文档

01 / INSTALL

安装到目标项目

先克隆 源仓库，在目标项目运行以下模板并替换源码路径。安装器先校验源码，只复制十个运行文件；目标已存在就停止。

PowerShell
python 'C:\path\to\research-asterism\scripts\install_skill.py' --target '.agents\skills\research-methodology'
python 'C:\path\to\research-asterism\scripts\install_skill.py' --target '.agents\skills\research-methodology' --check

--check 只核对字节，不写入。重新开启宿主会话刷新发现；完整源码和最小运行安装的核验方式不同。POSIX、更新与详细说明 →

02 / INVOKE

可以只有主题，也可以带材料

输入模板
使用 $research-methodology。
请根据当前主题或材料，界定主张与证据范围，
给出能够改变判断的下一步；缺失信息明确标注。

已有项目时，加入当前决策、相关记录、资源与数据边界。若宿主没有发现技能，可明确要求读取 SKILL.md，但这不等于自动发现已验证。

03 / CAPABILITIES

能力来自当次会话

工具缺失时，保留证据边界
能力可做什么缺少时
检索与阅读查原始来源、最近邻及具体支持给暂定地图与待核实项
分析与执行在授权内核算、反例或验证给设计，区分计划与结果
项目记录沿用已有定义与历史用短决策记录，不另建强制体系

不自动启动旧项目、训练、付费工具或公开材料。一次调用不授予额外权限。

所有构造案例，无需 JavaScript

方法地图：分布变化

先界定目标群体与信息时点。方法假设不是实测成绩，当前无性能数据，不能排名。

想法验证：不可比报告

内部区分能力与外部校准不是同一目标量。先查报告支持，再设计匹配对照，不由不同协议宣称优越。

结果诊断：方向不稳定

分清独立制备单位与重复读数，检查干预与测量。证据不足不等于等效，也不等于方向不可能。
