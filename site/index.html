02 / THE STANDARD

好的判断，
经得起条件改变。

01

有引用，还要有支持。

核对材料实际支持哪一句结论。把来源事实、推断和待验证假设分别说清。

02

有需求，才谈适用。

应用需要什么，与方法测得什么，放在两张不同的矩阵里。缺证据不等于表现差。

03

有新名字，不等于新贡献。

比较最接近的旧机制。模块组合和检索未命中，都不能单独证明新颖性。

04

有负结果，也有下一步。

反例与失败收缩结论的范围。用更能区分解释的验证，决定继续、调整或停止。

03 / GET STARTED

一个主题。
就能开始。

在支持 Agent Skills 的宿主中使用。
无需绑定特定检索服务或 MCP。

  1. 01

    安装完整目录

    先从 GitHub 克隆或下载源码。在你的目标项目目录运行以下 PowerShell 模板；将源路径替换为克隆目录 research-asterism 的实际位置。安装目录仍为 research-methodology，只复制发布清单中的文件，目标存在时停止。

    WINDOWS / POWERSHELL
    $source = 'C:\path\to\research-asterism'
$target = Join-Path (Get-Location) '.agents\skills\research-methodology'
if (Test-Path -LiteralPath $target) { throw 'Target already exists' }
$files = (Get-Content -LiteralPath (Join-Path $source 'release-files.json') -Raw | ConvertFrom-Json).files
foreach ($file in $files) {
    $destination = Join-Path $target $file
    New-Item -ItemType Directory -Force -Path (Split-Path $destination) | Out-Null
    Copy-Item -LiteralPath (Join-Path $source $file) -Destination $destination
}
  2. 02

    在目标项目新开会话

    刷新技能发现后，输入技能名和当前问题。也可以直接请代理读取源目录的 SKILL.md。

    YOUR FIRST PROMPT
    使用 $research-methodology。
我想让图书馆找书更省力。
请帮我形成可检验的小问题，选择最低成本的区分验证。
  3. 03

    让判断跟着证据更新

    提供论文、想法或实验观察，说明现在需要作什么决定。沿用已有项目记录，按实际权限使用工具。
