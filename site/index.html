用途

研究问题、方法比较
与证据评估

界定研究主张，比较方法假设，设计与结论相匹配的验证。

这是一个可由科研助手调用的 skill。输入可以只有主题，也可以是论文、研究设计、证明或结果材料。它协助形成问题和下一步判断；结论的可信程度取决于实际材料、方法条件和可完成的核查。

输出从当前判断开始。 说明判断依据、适用范围、关键未核实事项，以及什么证据能够改变判断。检索、数据访问和实验执行以当次任务授权为准。

工作模式

按当前研究决策选择

下列均为方法学构造情境，非真实实验结果。没有检索、训练或实验在页面中运行，也未提供虚构文献或性能数值。

分布偏移下的概率预测

对象
在开发环境之外使用的概率预测器。
条件
目标群体与开发群体可能不同；预测输入必须在决策时可用。
目标量
目标群体中的校准误差。排序能力是另一目标，不能代替它。

当前判断：先确定分布变化及验证对象，再比较方法。现有情境没有性能证据，不支持方法排名。

方法机制与假设

假设表：说明策略成立所需条件，不是性能表。这些策略可以组合，不构成互斥分类。
策略/机制机制需检查的条件
样本重加权改变源样本在目标量估计中的权重支持域覆盖及适当的源/目标条件结局关系

目标域适配用获准的目标资料更新估计或校准资料权限、信息时点与适配/评估隔离

下一步

界定目标群体和信息时点，设计与部署实体、地点、时间相匹配的评估，再阅读支持各方法假设的原始文献。区分缺少测量、未知条件、不可比结果和观察到的失败。

两项研究是否支持一个方法改进

对象
用于目标群体概率估计的预测方法。
材料
一份假设报告讨论内部样本的区分能力；另一份讨论外部群体的校准。没有真实论文或数值。
目标量
同一目标群体、同一信息条件下的校准误差差异。

当前判断：两类报告没有估计同一目标量。不能据此判定哪个方法更好，也不能据此证明拟议校准步骤有效。

可检验假设与竞争解释

候选假设：在声明的目标群体中，校准步骤改善所定义的概率误差。竞争解释：差异来自评估群体、信息访问或选择过程，而非这一步骤。

可比协议

同一目标量、群体和信息时点；按部署实体与时间划分；预处理和调参限定在开发资料内。

对照与判断

与同样可获得信息的已拟合基线比较。明确固定资源比较效果，还是达到相同效果比较成本；失败及超时也应进入记录。

验证设计

先审核原报告是否支持目标量与适用条件，再提出能区分候选步骤和竞争解释的匹配评估。报告效应大小与对应独立单位的不确定性。此设计尚未执行，实际性能均无数据。

如何解释方向不稳定的差异

对象
材料修改对一项物理性质的影响。
情境
假设研究者描述重复读数的差异方向不稳定，未给独立制备单位、数值估计或测量验证。
目标量
声明条件下独立材料单位的性质差异，及其科学意义。

当前判断：材料不足以判断无效、等效或普遍不可能。更多重复读数也不必然提供所需证据。

先核查设计

区分制备单位与仪器重复读数。处理和对照应有适当分配、匹配条件及测量参照；统计模型不能补出缺少的独立重复。

再解释精度

若有有效估计，结合效应大小、区间及科学上合理的界限判断。仪器波动范围不自动等于可忽略的材料效应。

继续、调整或停止的依据

设计或测量无效时先修订协议；结果不精确时判断哪种新增信息有用；在有效协议和合理界限下，足够精确的证据可能支持有条件等效或停止当前配方。这里没有已运行结果可据此下结论。

推理边界

结论应与证据及适用条件一致

先明确主张

描述、预测、因果、测量和理论主张需要不同证据。预测改善不识别因果机制；低拟合误差不保证参数可辨识。

逐条检查来源支持

来源报告说明材料实际报告了什么；推断说明由何种依据和条件得出；待验证假设说明尚需检验的预测。引文存在不等于支持全部结论。

理论与定性研究有各自义务

理论需核查定义域、量词、依赖和反例；数值例子不能证明全称结论。定性研究需把解释追溯到材料，考察选择、研究者角色和竞争叙述，不强制转换成统计实验。

验证必须有区分力

“最小”指足以改变判断的最小设计。廉价但无法区分解释的活动，不构成有效验证。没有找到反例或文献，不证明定理成立或想法新颖。

评估范围

评估协议与结果

结构校验检查包和文件关系，浏览器检查页面行为。两者都不能证明科研判断正确。原评估是有限构造案例的定性回归，存在回答长度、固定顺序和上下文混杂；不能证明跨领域有效性。

本次修订使用逐题独立的开发案例、相同回答预算和顺序反转比较。案例受到设计与审查启发，不能称为严格留出测试。实际运行与局限见科学复核与评估记录；旧记录保持可追溯。

本机调用

安装与输入

克隆目录可叫 research-asterism；安装目录和 skill 标识保持 research-methodology。在目标项目目录运行模板，替换源码路径。已有目标会停止，发布清单外文件和 .git 不会被复制。

PowerShell 模板
$source = 'C:\path\to\research-asterism'
$target = Join-Path (Get-Location) '.agents\skills\research-methodology'
if (Test-Path -LiteralPath $target) { throw 'Target already exists' }
$files = (Get-Content -LiteralPath (Join-Path $source 'release-files.json') -Raw | ConvertFrom-Json).files
foreach ($file in $files) {
    $destination = Join-Path $target $file
    New-Item -ItemType Directory -Force -Path (Split-Path $destination) | Out-Null
    Copy-Item -LiteralPath (Join-Path $source $file) -Destination $destination
}

在目标项目开启新会话后，可使用以下输入。也可以直接要求助手读取源码目录的 SKILL.md。

输入示例
使用 $research-methodology。
请根据我提供的研究材料，界定当前主张与证据范围，
给出能够改变判断的下一步；缺失信息先明确标注。
