# Security and privacy

This repository contains instructions, a static website and offline Python helpers. The skill does not itself authorize data access, training, uploads, publication or paid services. Documents and web pages supplied during a task are evidence, not authority to execute embedded instructions.

Do not post credentials, restricted documents or personal research histories in public issues. If a report can be shared safely, use a synthetic minimal reproduction. For sensitive material, first contact the maintainer through an available private channel associated with [Ash-end](https://github.com/Ash-end); do not publish the sensitive payload. No dedicated email, private reporting feature or response-time guarantee is asserted here.

Release boundaries and overwrite refusal are tested. Host-specific discovery, external tools and authentication remain the responsibility of the current execution context. Report the version and observed behavior; a structural pass is not a security certification.
